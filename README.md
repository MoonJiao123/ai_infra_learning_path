# C++ 起步实验室

13 课，4 周，面向零基础阅读与独立写代码。第一周变量/控制流/函数；第二周引用/内存/所有权；第三周移动与容器；第四周类/LRU/工具链。建议每天 30–60 分钟，先读与预测，再写和测试，隔天重新独立完成一次。

## 启动

需要 Python 3、clang++（本机已经验证）。双击 `start.command`，或在此目录执行：

```sh
python3 server.py --port 8765
```

浏览器访问 http://127.0.0.1:8765 。终端 Ctrl+C 停止。更换端口用 `--port 8766`，浏览器地址也需相应改变。无需 npm、GPU、模型密钥或网络。

## 使用

练习模式编辑函数/类，头文件、main 与断言由服务补齐。自由模式可编译完整程序。每课参考答案折叠显示，使用答案通过测试也会记录为通过，请自己复习确认掌握。通过记录代表曾通过测试；修改草稿不会清除历史通过记录。测试展示了重要边界，不构成对所有输入的形式证明。

草稿、通过记录和预测答案保存在当前浏览器 localStorage，刷新或重启服务可恢复；自由模式与练习模式分别保存。恢复本课初始代码只清除当前模式草稿；重置全部需要确认并清除全部记录。浏览器隐私模式、清除网站数据或换端口会影响恢复。没有云同步。

离线助手按术语检索固定知识库，不是生成式 AI；复制上下文后可在 Codex 继续提问。课程与参考答案均在本地，展开前请先自行尝试。

## 本地执行边界

仅监听 127.0.0.1；精确 Host、同源 Origin 与 CSRF token 校验；最多 2 个并发编译、源码 40 KB、请求 70 KB、编译 20 秒、运行 3 秒、输出 24 KB。每次使用独立临时目录并清理，超限杀死进程组。不提供操作系统权限隔离、文件系统隔离、网络隔离或内存用量硬限制。**只运行自己编写、可信的学习代码，这不是恶意代码安全沙箱。** 不要用它运行不可信下载代码。不要修改监听地址对外公开。

网页检查器可启用 AddressSanitizer 与 UBSan。CMake 示例位于 tools-demo：

```sh
cmake -S tools-demo -B build -DSANITIZE=ON
cmake --build build
./build/demo
lldb ./build/demo
```

CMake/lldb 是否可用取决于本机工具安装。网页编译不依赖 CMake。当前仅实现第一阶段，没有后续 LLM/GPU 课程。
